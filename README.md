# 劉宸銨 (Chen-An Liu) - 面試作品集

## 🚀 專案啟動

### 環境要求
- Node.js 16.x 或更高版本
- npm 或 yarn

### 安裝依賴
```bash
npm install
# 或
yarn install
```

### 開發模式
```bash
npm start
# 或
yarn start
```

應用會在 `http://localhost:3000` 啟動

### 構建專案
```bash
npm run build
# 或
yarn build
```

## 📁 專案結構

```
├── public/
│   └── index.html          # HTML 根文件
├── src/
│   ├── App.jsx            # 主要 React 元件
│   ├── index.js           # React DOM 初始化
│   └── index.css          # Tailwind CSS 導入
├── package.json           # 依賴配置
├── tailwind.config.js     # Tailwind CSS 配置
└── .gitignore            # Git 忽略規則
```

## 📦 主要依賴

- **React 18** - UI 框架
- **Tailwind CSS** - 樣式定制
- **Lucide React** - 圖標庫

## ✨ 主要功能

1. **Hero Section** - 個人介紹頁面
2. **About Me** - 背景與技能總結
3. **Personal Positioning** - 核心價值定位
4. **Core Advantages** - 個人核心優勢
5. **Skills** - 技能庫展示
6. **JUDGE AI Project** - 核心專題展示
7. **Other Projects** - 其他實作專案
